# D15: Public note upkeep: reset, moderation or neither

Status: `OPEN`

## Context

The public note never expires (D06) and anyone can edit it. It will fill with junk, and
it can reach the 2 MB cap, after which it is read only for everyone.

## Options

- Leave it: it is a playground.
- Reset it on a schedule (for example nightly) to a seeded welcome text, with a Durable
  Object alarm.
- Reset it by hand when needed (a protected admin route or a wrangler command).

Gerard decides.
