# D09: Docs are rewritten, never amended

Status: `DECIDED`

## Decision

When reality changes, rewrite the affected doc so it reads as if written fresh today. No
"update:" paragraphs, no "previously" notes, no changelog sections in docs. Git history is
the changelog.

Decision files are the exception in one way: a superseded decision gets its Status line
changed and a pointer to the decision that replaces it.
